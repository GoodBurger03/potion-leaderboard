# Potion Leaderboard

Potion Leaderboard is a gamified platform for Solana memecoin traders. The application displays a leaderboard of traders, including key metrics such as wallet address, profile picture, X account handle, follower count, and P&L. The app supports search, filters, pagination, and a responsive design.

## Features

- Search by wallet address or X account handle
- Filters for followers, P&L, and positive P&L
- Pagination
- Responsive design
- Copy wallet address to clipboard

## Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/potion-leaderboard.git
   cd potion-leaderboard
   ```
   Install dependencies:
    ```
    npm install

    ```
Start the app:
   ```
    npm start
   ```
